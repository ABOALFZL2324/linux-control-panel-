# ServDock — Linux Control Panel & Docker Desktop 🚀

یک نرم‌افزار دسکتاپ مدرن و قدرتمند برای ویندوز جهت اتصال، مانیتورینگ، مدیریت کامل سیستم‌های لینوکسی، کانتینرهای داکر و وب‌سرورهای LAMP/LEMP با رابط کاربری شیشه‌ای (Glassmorphism) و به زبان فارسی.

---

## ✨ امکانات و قابلیت‌های کلیدی

### 🐳 مدیریت پیشرفته داکر (Docker Desktop Style)
- **مدیریت کانتینرها:** مشاهده وضعیت لحظه‌ای، استارت، توقف، ریستارت، پاکسازی و حذف اجباری (`rm -f`).
- **ویرایش و بازسازی هوشمند (Recreate):** تغییر نام بدون وقفه، تغییر پورت‌ها و متغیرهای محیطی با بازسازی خودکار کانتینر.
- **نگاشت منعطف پورت‌ها (Port Forwarding):** تعیین مجزای پورت میزبان و پورت کانتینر با پروتکل‌های TCP/UDP و پورت‌های آماده (80, 8080, 443, 3306, 5432, 6379, 9000).
- **مدیریت استارت‌آپ و بوت:** کنترل راه‌اندازی خودکار کانتینرها با سیاست‌های Restart (`unless-stopped`, `always`, `on-failure`) و مدیریت سرویس اصلی داکر در systemd.
- **داکر هاب و میرورهای داخلی:** جستجوی زنده در مخزن Docker Hub، تنظیم میرورهای تحریم‌شکن داکر، و پریست‌های ۱-کلیکه (WordPress, Redis, PostgreSQL, Portainer, Nginx, Python).
- **صف و پیشرفت دانلود ایمیج‌ها:** دانلود مستقیم ایمیج‌ها روی سیستم لینوکس با اینترنت سرور، نوار پیشرفت زنده، صف پردازش و پشتیبانی از بارگذاری فایل‌های `tar` / `iso`.
- **راهنمای یکپارچه اتصال به پایگاه‌داده میزبان:** راهنمای آی‌پی دروازه شبکه داکر (`172.17.0.1`) جهت اتصال بی‌دردسر کانتینرها به MySQL/PostgreSQL نصب‌شده روی هاست.

### 🌐 مدیریت وب‌سرور و پایگاه داده (LAMP / LEMP Stack)
- **کنترل وب‌سرور:** مدیریت وضعیت، استارت، استاپ، ری‌استارت و تست کانفیگ (`configtest`) وب‌سرورهای Apache2 و Nginx.
- **پایگاه‌داده MySQL / MariaDB:** مشاهده تعداد دیتابیس‌ها، وضعیت سرویس و پورت ۳۳۰۶ به همراه آی‌پی دسترسی کانتینرها (`172.17.0.1:3306`).
- **محیط اجرایی PHP:** بررسی نسخه فعال، سقف مصرف حافظه (`memory_limit`) و حداکثر حجم مجاز آپلود فایل (`upload_max_filesize`).
- **نصب آسان ۱-کلیکه:** امکان استقرار خودکار پکیج کامل LAMP روی لینوکس.

### 🔒 مدیریت شبکه و Tailscale VPN + Funnel
- **اتصال شبکه مش Tailscale:** مشاهده آدرس‌های اختصاصی 100.x، وضعیت گره‌ها و شبکه امن.
- **اشتراک‌گذاری عمومی (Tailscale Funnel):** فعال‌سازی و انتشار سرویس‌های محلی به اینترنت عمومی از طریق دامنه امن و رایگان HTTPS با قابلیت کپی سریع URL.

### 📁 فایل منیجر ریموت و تبادل فایل (SFTP)
- مرور پوشه‌ها و فایل‌های سرور لینوکس با سرعت بالا.
- ویرایشگر متنی آنلاین درون‌برنامه‌ای با قابلیت ذخیره مستقیم روی سرور.
- آپلود مستقیم فایل از ویندوز و دانلود به کامپیوتر.
- دانلود مستقیم فایل از لینک اینترنتی (URL) روی سرور لینوکسی.
- بارگذاری ایمیج‌های داکر از فایل ایزو/تار موجود روی سرور.

### 📊 داشبورد و مانیتورینگ زنده سخت‌افزار
- درصد بار پردازنده (CPU) و نمودار فعالیت.
- مصرف رم (RAM)، حافظه Swap، فضای دیسک و پارتیشن‌ها.
- نرخ تبادل شبکه (دانلود/آپلود زنده).
- مدت‌زمان روشن بودن سرور (Uptime) و میانگین بار (Load Average).

### ⚡ ترمینال و ریموت دسکتاپ (RDP / VNC)
- کنسول ترمینال تعاملی وب‌سوکت برای اجرای مستقیم دستورات باش با دسترسی root.
- دسترسی سریع به محیط گرافیکی لینوکس (XRDP / Guacamole).

### ۱. پیش‌نیازها

- پایتون ۳.۱۰ یا بالاتر

### ۲. نصب وابستگی‌ها
پروژه را کلون کرده و کتابخانه‌های مورد نیاز را نصب کنید:

```cmd
git clone https://github.com/ABOALFZL2324/linux-control-panel-.git
cd linux-control-panel-
pip install -r requirements.txt
```

### ۳. اجرا
فایل **`run.bat`** را اجرا کنید یا دستور زیر را در ترمینال بزنید:

```cmd
python main.py
```

## 🛡️ معماری اتصال
نرم‌افزار از معماری دوگانه هیبریدی بهره می‌برد:
1. **اتصال پایه SSH/SFTP (بدون نیاز به نصب هیچ ابزاری روی لینوکس):** بلافاصله پس از ورود اطلاعات سرور، تمامی امکانات از طریق SSH استاندارد در دسترس خواهند بود.
2. **ایجنت بهینه‌سازی‌شده ServDock:** برای عملکرد فوق‌العاده سریع و ارسال بلادرنگ متریک‌ها، یک ایجنت پایتونی سبک و ایزوله به عنوان سرویس لینوکس مستقر می‌گردد.
